## 触发

学完有向图的四类边分类（tree/forward/back/cross，靠 pre/post 区间relative position
判断），回头问"无向图是不是只剩两类"，自己先给了个结论。

## 卡点 / 误解

**我原以为**剩下的两类是"嵌套"和"交集为空"——也就是以为 cross（不相交）作为
一个类别还保留着，只是被划分得更粗糙。

**实际不是。** 不相交在**有边相连的两点之间彻底不可能**——不是被合并进别的
名字，是这种区间关系压根不会出现。消失的是 forward 和 cross 两个名字，剩下
tree 和 back 两个，而这两个恰好都属于"嵌套"这一种区间关系。准确说法是：
**四个边的名字砍掉两个，剩下的两个碰巧同属一种区间关系**，不是"区间关系本身
从四种粗化成两种"。

判决性实例（自己构造的，用来测试这个结论）：图上只有 A-B、A-C 两条边，
**不连 B-C**，从 A 出发跑 DFS，A 的邻接表顺序 [B,C]：

```
explore(A): pre(A)=1
  explore(B): pre(B)=2, post(B)=3
  explore(C): pre(C)=4, post(C)=5
  post(A)=6
```

`B[2,3]` 和 `C[4,5]` 区间确实不相交！第一反应是"这不就是反例吗"——但停下来
问一句：**B 和 C 之间有边吗？没有。** 不相交这件事从来只对"有边相连的两点"
才被禁止，B、C 之间没有边，它们不相交完全合法，跟"cross edge 不存在"这个命题
毫无冲突。这个例子真正的价值不是反驳了结论，是划清了命题的适用边界——
它只管"有边"的点对，不管所有点对。

## 关键 insight

"无边可以不交，有边必须嵌套"这条边界背后的证明机制，和 Q1.2 那条
"explore 标记的点恰好等于路径可达的点"的可达性论证是**同一套逻辑的复用**：
设 `(a,b)` 有边，a 先被发现。a 的活跃期 `[pre(a),post(a)]` 里，a 自己的循环
一定会扫到这条边——如果 b 那时还没被别的分支碰过，a 会立刻把它拽进来
（递归探进去）；如果已经被碰过，那也是在 a 结束之前发生的。**无向边能
双向走，这就保证了先发现的那个点，一定能在自己活跃期内"够到"另一端**，
不给"两个独立分支、互不相交"留出任何空间。这条论证本身跟图是不是无向
没有关系（是任意两点的区间关系只有嵌套或不交、不可能部分重叠这个一般
事实——根源是 DFS 递归调用栈的后进先出结构，跟括号匹配同构）；无向图
额外加的那层，是"只要有边，不交这个选项被彻底堵死，只剩嵌套"。

有向图那边不能这样简化——不相交（cross）依然合法，但方向被钉死：见
[[one-inequality-replaces-four-cases]]，那条统一引理里"被排除的唯一情况"
和这里"无向图的不交彻底消失"，都是同一种"边的存在限制了区间能有的相对
位置"的具体表现，只是无向图限制得更狠（连 cross 这个选项都没了）。
