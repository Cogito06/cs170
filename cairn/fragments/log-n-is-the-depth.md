## 触发

推完主定理三种情况（[[per-node-not-per-level]]）之后追问：
过渡态 `n^d log n` 里那个 log 到底是从哪冒出来的？

## 卡点 / 误解

**我原以为**那个 log n 是某个「算出来的」函数——好像求和过程里凭空生出了一个对数运算。

**不是。它就是递归树的深度 `log_b n`，从头到尾只有这一个身份。**

它平时看不见，是因为 case 1 和 case 3 里几何级数被**一端**支配，
于是有多少项根本不重要——树砍成 5 层还是 1000 层，答案只差常数，层数被吞掉了：

```
r ≠ 1 :  Σ r^k 的「有效项数」= O(1)   → 层数不可见
r = 1 :  Σ 1   的项数        = L     → 层数就是答案
```

只有天平持平、没有哪一层能独吞答案时，你才**不得不去数一数到底有几层**。

反过来当口诀用：看见 `n log n`，该想的是**「这是个每层等重的分治」**，
而不是「这里有个对数运算」。

## 关键 insight

再深一层——这根本不是主定理特有的，它是**幂函数在指数临界点退化成对数**的通用机制。

令 ε = 离边界的距离：`ε = log_b a − d`，于是 `r = b^ε`，`r^L = n^ε`。
代进几何级数求和公式，**三种情况被一个式子统一**：

```
                n^ε − 1
T(n)  ≈  n^d · ─────────
                 ε·ln b

ε > 0 :  n^ε 支配  →  n^(log_b a) / (ε ln b)        叶重
ε < 0 :  n^ε → 0   →  n^d / (|ε| ln b)              根重
ε = 0 :  0/0 —— 极限 lim (n^ε−1)/ε = ln n  →  n^d log_b n
```

那个极限 `lim_{c→0} (X^c − 1)/c = ln X` 在微积分里见过同一张脸：

```
  N              N^(p+1) − 1        令 c = p+1        N^c − 1
  ∫ x^p dx  =  ─────────────   ───────────────→   ─────────  ──→ ln N
  1                p + 1                              c        c→0

  p = −1 时退化成 ln N          ←→          ε = 0 时退化成 log n
```

**结构完全同构。** 统一说法：*一族以指数为参数的幂函数，在某个参数值上分母出现零点，
那一点的答案就是对数。* 调和级数 `Σ1/k ~ ln n` 是同一现象的第三张面孔。

两条推论：

**(a) log 是极点的残迹。** `1/|ε|` 在边界两侧都爆炸——越靠近边界，case 1 和 case 3
的常数因子越烂。所以 `n^d log n` **不是「第三种情况」**，它是那个发散常数被正则化
之后留下的东西。

**(b) log 是最便宜的发散。** 对任意 ε>0 都有 `1 ≪ log n ≪ n^ε`。边界必须给出一个
严格夹在 case 1 的常数和 case 3 的 `n^ε` 之间的因子——`log n` 是这条缝里唯一自然的
居民，**答案不可能是别的**。
